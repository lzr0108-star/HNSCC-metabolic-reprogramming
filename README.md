# HNSCC glycolysis–OXPHOS metabolic reprogramming — reproducible code

This repository contains the R code used for the single-cell, spatial and
bulk multi-omics analysis of head and neck squamous cell carcinoma (HNSCC),
organised around a **dual-axis metabolic score**: the glycolysis/lactate axis
(**GL**) versus the mitochondrial oxidative phosphorylation axis (**OM**).
The disease-phenotype backbone is **recurrence and lymph-node metastasis**.

This is a secondary analysis of publicly deposited data; no new experiments
are included.

## Scientific question

How does the GL ↔ OM metabolic state of malignant HNSCC cells shape their
molecular phenotype, cell–cell communication and spatial distribution, and
is it associated with lymph-node metastasis and clinical prognosis?

## Data sources

| Data | Type | Scale | Purpose |
|---|---|---|---|
| [GSE103322](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE103322) (Puram, Cell 2017) | scRNA-seq | 5,901 cells (2,500 malignant), 20 patients | Main single-cell analysis |
| [GSE181300](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE181300) | 10x Visium | 8 sections, 12,038 spots | Spatial validation |
| [TCGA-HNSC](https://portal.gdc.cancer.gov/projects/TCGA-HNSC) | bulk RNA-seq | 566 samples (520 primary tumours) | Expression & prognosis |

## External source project (required for a full end-to-end run)

Steps 00–02 (object construction, QC/clustering/annotation, CopyKAT), the raw
Visium sample folders and the TCGA GDC downloads are reused from the
companion `HNSCC复现` project. That project is **not bundled here** because it
contains multi-gigabyte objects. Point this repository to it in either way:

- set the environment variable `HNSCC_PROJECT_ROOT` to its full path, or
- place it as a sibling folder named `HNSCC复现` next to this repository.

The path is resolved automatically by `config.R`; no script needs editing.

## Workflow (run the scripts in numeric order)

1. **00–02 (prerequisites, reused):** build the GSE103322 object, QC,
   clustering and annotation (9 cell types; 4 malignant sub-programs), and
   CopyKAT confirmation of malignant cells (zero false positives).
2. **03 — dual-axis scoring:** GL (296) and OM (285) gene sets, four scoring
   algorithms (AddModuleScore, AUCell, ssGSEA, singscore), median four-quadrant
   grouping, and independent scMetabolism validation (OXPHOS–OM rho 0.906).
3. **04 — metastasis pairing & DEG:** paired primary–lymph-node tests across
   8 patients (directional, trend-level evidence), plus HighGL vs LowGL DEG
   demonstrating systematic GL ↔ OM antagonism and a Warburg–invasive program.
4. **05 — hdWGCNA:** three functional co-expression modules (epithelial,
   metabolic-enzyme, cell-cycle) with module–trait correlations.
5. **06 — CellChat:** high-glycolysis cells strengthen ECM/basement-membrane
   and pro-metastatic communication (LAMININ, COLLAGEN, SPP1).
6. **07 — ten-algorithm machine learning:** scoring genes are removed before
   feature construction; patient-level 7:3 split; AUC 0.833–0.996; consensus
   markers such as SCD, SLC7A5, FSCN1 and CXCR7.
7. **08 — spatial:** metabolic HubScore, GL/OM spatial scores and manual
   ggplot H&E overlay (a workaround for the Seurat 5 VisiumV2 rendering issue).
8. **09 — TCGA validation:** signature KM survival (log-rank p = 0.0035),
   multivariable Cox (HR = 1.29, p = 0.00052) and tumour–normal expression.

## Reproducing the analysis

```r
# From within the repository (R working directory anywhere under the root):
for (s in c("00_build_object.R", "01_QC_cluster.R", "01b_annotate.R",
            "02_CopyKAT.R", "03a_build_genesets.R", "03b_multi_scoring.R",
            "03c_grouping.R", "03d_scmetabolism.R", "03e_visualize_scores.R",
            "04_DEG_metabolic.R", "04_transfer_pairing.R",
            "05_hdWGCNA_metabolic.R", "06_CellChat_metabolic.R",
            "07_ML_metabolic.R", "08_Spatial_metabolic.R",
            "09_TCGA_metabolic.R")) {
  source(file.path("scripts", s))
}
```

Each script auto-locates `config.R`, reads the previous step's object, and
writes its own RDS/CSV outputs and figures. The intermediate `*.rds`,
`*.rda`, TOM and zip archives are excluded via `.gitignore` and are
regenerated by the scripts.

## Methodological boundaries

- GSE103322 provides only `log2(CP100K+1)` values, with no raw counts and no
  genuine mitochondrial-encoded genes; all metabolic findings are phrased as
  **transcriptional activity/potential**, never as flux.
- All GL/OM scoring genes are removed from the ML feature pool before model
  fitting to avoid circular reasoning, and data are split at the patient level.
- The 8-patient primary–lymph-node comparison yields no p < 0.05 and is
  reported honestly as trend-level evidence; the significant TCGA prognosis is
  a separate, larger-sample line of evidence and is not conflated with it.

## Software environment

R 4.6.x / Bioconductor 3.23; Seurat, hdWGCNA, WGCNA, CellChat, caret, GSVA,
AUCell, singscore, scMetabolism, TCGAbiolinks, msigdbr and related packages.
Random seeds: 20260811 (sampling), 20260812 (spatial/TCGA).
